# flexnetos/

FlexNetOS extensions for AionUi. Everything here is **additive** — this directory
does not exist in upstream `iOfficeAI/AionUi`. It is the only place (along with
`.aionui-data/`) where FlexNetOS-owned code lives in this fork.

## Why a separate namespace

The fork's `main` branch is updated automatically every six hours from upstream
(`.github/workflows/sync-upstream.yml`). Any edit to an upstream-owned file
risks merge conflicts on every sync. By confining all FlexNetOS additions to
new top-level directories, the fork stays conflict-free indefinitely.

See `docs/CONTRACT.md` for the zero-upstream-touch contract this fork honors,
and `docs/INSTALL_PROOF.md` (generated by the install proof script) for the
most recent evidence run.

## Layout

```
flexnetos/
├── README.md                    you are here
├── launch/                      run-in-place entry points
│   ├── run-in-place.sh          single script all launchers wrap
│   ├── aionui-dev.desktop       Linux app-menu launcher (dev mode)
│   ├── install-launcher.sh      symlinks .desktop → ~/.local/share/applications/
│   └── uninstall-launcher.sh    removes the symlink
├── addons/                      drop-in extension templates
│   └── README.md
└── docs/
    ├── RUN_IN_PLACE.md          three run modes, where each looks for config
    ├── extending.md             how to add MCP servers / custom agents without
    │                            touching upstream code
    └── CONTRACT.md              the zero-upstream-touch contract + verifier
```

`.aionui-data/` (sibling directory at repo root) holds runtime config and
state. Templates committed there bootstrap the app on first run.

## Quick start

```bash
flexnetos/launch/run-in-place.sh           # dev mode (electron-vite dev)
flexnetos/launch/run-in-place.sh --webui   # web-UI mode (browser)
flexnetos/launch/install-launcher.sh       # add AionUi to the GNOME app menu
```

All three modes write userData inside `<repo>/.aionui-data/` because the
wrapper sets `XDG_CONFIG_HOME` to that directory before invoking Electron.
